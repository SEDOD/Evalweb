# EvalWeb Solutions — site statique

Site livré en HTML, Tailwind CSS via CDN et JavaScript vanilla.

## Utilisation
Ouvrir `index.html` dans un navigateur ou servir ce dossier avec un serveur statique.

## Identité visuelle
Le logo fourni est intégré dans `assets/evalweb-logo.png` et utilisé dans l’en-tête et le pied de page. La palette reprend le bleu profond, l’orange et le vert du logo, avec une direction plus chaleureuse et humaniste.

## Pages
Accueil · À propos · Nos pôles · Services · Produits · Réalisations · Formations · Actualités & ressources · Contact.

Le formulaire de contact est actuellement une démonstration front-end : il affiche un message de confirmation et devra être relié à votre solution d’envoi préférée.
